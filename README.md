# Investoren-Dashboard

Offline-fähiges Portfolio-Dashboard (Portfolio Command Center) als einzelne HTML-Datei.

**Live-Version:** https://lucabudimir-prog.github.io/-ffentlich/

- Kennzahlen, Positions-Karten, Donut- und Linien-Chart
- Läuft komplett ohne Server — `index.html` einfach im Browser öffnen
- Eingebetteter Kurs-Snapshot (Alpha Vantage); optionaler Live-Modus mit eigenem API-Key (siehe `CONFIG` im Quelltext)

Keine Anlageberatung.
